1. 처리하는 개인정보와 목적

이메일로 가입이메일, 비밀번호(복호화할 수 없게 암호화해서 저장), 약관 동의 일시 · 회원 식별, 로그인, 비밀번호 재설정 안내
Google로 가입이메일, Google 계정 식별자 · 회원 식별, 로그인
퇴근길 설정회사역, 집역, 귀가 목표 시각, 역 진입 시간 · 들를 수 있는 시간 계산, 다른 기기에서 같은 설정 사용
서비스 이용 중장소 검색어, 검색한 장소의 좌표 · 장소 검색과 경유 시간 계산. 계정과 연결해 저장하지 않아요.
자동 수집접속 IP, 접속 일시, 앱 버전, 오류 기록 · 장애 대응, 부정 이용 방지(로그인 시도 제한)

이름, 전화번호, 연락처, 휴대폰 위치 정보는 받지 않아요. 최근 검색 기록은 휴대폰에만 저장되고 서버로 보내지 않아요.

2. 보관 기간

  • 계정 정보와 퇴근길 설정: 탈퇴할 때까지. 탈퇴하면 바로 삭제해요.
  • 로그인 유지 정보(토큰): 최대 14일. 로그아웃하거나 탈퇴하면 바로 폐기해요.
  • 비밀번호 재설정 링크: 30분.
  • 접속 기록: 보안을 위해 30일 보관한 뒤 삭제해요.

3. 제3자 제공과 처리 위탁

개인정보를 다른 회사에 팔거나 제공하지 않아요. 서비스를 운영하려고 아래 업체에 처리를 맡기거나 외부 기능을 사용해요.

서버 호스팅 업체서버와 데이터베이스 운영(계정, 퇴근길 설정 보관)
GoogleGoogle 로그인 확인. 사용자가 Google로 계속하기를 누를 때만 Google 계정 정보를 받아요.
카카오 (로컬 API)장소 검색. 검색어만 서버에서 보내고, 계정 정보는 보내지 않아요.
SK텔레콤 (TMAP API)장소와 역 사이 도보 시간 계산. 좌표만 보내고, 계정 정보는 보내지 않아요.
Google (Gmail)비밀번호 재설정 메일 발송(이메일 주소)

서버나 메일 발송 서비스가 국외에 있다면 여기에 이전받는 자, 국가, 이전 항목, 시기와 방법, 보유 기간을 적어요.

4. 파기 방법

보관 기간이 끝나거나 탈퇴하면 데이터베이스에서 다시 복구할 수 없게 지워요.

6. 안전하게 지키는 방법

  • 비밀번호는 BCrypt로 암호화해 저장하고, 원래 값은 저장하지 않아요.
  • 앱과 서버 사이 통신은 모두 HTTPS로 암호화해요.
  • 휴대폰에 저장하는 로그인 정보는 암호화해요.
  • 로그인 시도가 반복되면 잠시 막아요.
  • 서버와 데이터베이스는 운영자만 접근할 수 있어요.
